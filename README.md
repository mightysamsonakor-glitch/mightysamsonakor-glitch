## 🚀 What I'm building

### [GlobalRate](https://www.globalrate.space) — live now
A community marketplace for students and expats in Lithuania: **live currency rates, peer-to-peer money exchange, rooms to let, gadgets and rentals**, with accounts, built-in chat, an admin panel and a mobile-first design.

[![Visit GlobalRate](https://img.shields.io/badge/Visit-globalrate.space-7c3aed?style=for-the-badge)](https://www.globalrate.space)
[![Source code](https://img.shields.io/badge/Source-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/mightysamsonakor-glitch/globalrate)

Built end to end by me: REST API, authentication and sessions, email (welcome + password reset), photo uploads, admin tooling, deployment on Render with a persistent disk, and a custom domain.

### [Naira Ledger](https://github.com/mightysamsonakor-glitch/naira-ledger) — fintech backend
A wallet and payment ledger API built the way fintechs do it: **double-entry bookkeeping** enforced in PostgreSQL, **idempotent payments**, row locking that **never overspends** under concurrent load, and **signed Paystack-style webhooks**. TypeScript, 17 integration tests, Docker and GitHub Actions CI.

[![Source code](https://img.shields.io/badge/Source-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/mightysamsonakor-glitch/naira-ledger)
